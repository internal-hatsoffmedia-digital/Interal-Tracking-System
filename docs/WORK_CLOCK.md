# Work clock and commitments

In **My Work**, select an assigned project and optionally your task. Start when work begins. Pause for breaks; resume to create the next working interval. Finish session saves time without completing the task. Use the task's Complete action to submit it.

The daily log uses IST. Refreshing or closing the browser does not pause a running timer. Pause before leaving; a session is capped at midnight IST and a new day requires a new start. Only one session may run per account. You can review earlier dates. Logs are private to the account and separate from existing manual hours/report totals.

When assigning, discuss the completion time with the employee, enter the committed date/time in IST, and confirm the agreement. The assignment saves that commitment as its delivery deadline. Later edits to the task deadline do not change the historical assignment snapshot. Existing assignments keep their original deadline without an invented commitment.

Dashboard image announcements advance every six seconds. Pause/Play and previous/next controls remain available. Swipe horizontally on touch devices. Reduced-motion users start playback explicitly.
