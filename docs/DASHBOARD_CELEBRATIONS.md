# Dashboard announcements and birthday wishes

Admin can open Dashboard → Today → Announcements & celebrations → Add images. Select up to eight JPG, PNG or WebP images, add a description, and preview the slider before publishing. Images are resized to 1280 pixels, compressed, and constrained to 2 MB per processed image / 6 MB combined. Everyone with an active signed-in account sees the shared slider. It advances every six seconds, pauses during focus/hover, provides previous/next/dot/pause controls, and respects reduced-motion preferences.

For a birthday, select **Birthday celebration** and its date in IST. The celebration appears on that date only. Each birthday has its own live wish room for all active signed-in colleagues. Wishes are limited to 280 characters, bounded to 100 messages in browser memory and have a five-second UI sending interval. They use private Supabase Realtime WebSocket broadcasts; no comments table, local storage, saved history, replay or daily database cleanup job is used. People joining later cannot retrieve earlier wishes. Refreshing or leaving the page clears the browser's wishes; midnight IST clears the room and removes the birthday panel. Published announcement images remain available to Admin under Manage announcements until removed.
